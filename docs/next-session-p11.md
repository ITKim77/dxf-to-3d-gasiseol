### 꺾임각 = **6.30°**

```
기둥 1→2   Δx 8,600  Δy    0   →   0.00°   간격 8,600
기둥 2→3   Δx 8,528  Δy −941   →  −6.30°   간격 8,580
```

**두 뷰(평면도·기초평면도)에서 같은 941 이 나온다.**

> ⚠ 지난 세션에 이걸 한 번 「8.7°」로 잘못 말했다. 전 색 각도 분포에 있던
> `81.3°/171.3°` 를 꺾임각으로 읽은 것인데, 구조 외곽선만(`ci=256`) 세면 그
> 대역이 없다 — **보조선 각도였다.** 기둥 축선에서 직접 잰 6.30° 가 맞다.
> **각도를 선 분포에서 읽지 말고 부재 좌표에서 재라.**

`(1,453,587, 436,249)` 의 Ø2,200 은 `CS-CONC-MAJR` 이고 x 가 19,971 떨어져 있다 —
**단면 A-A** 의 기둥 단면이지 평면도 기둥이 아니다.

## 1단계 — 꺾임의 정체 (여기서 멈추고 보고)

**캡처를 먼저 봐라.** 좌표만으로는 못 가른다.

1. **평면도** — 꺾이는 자리가 **기둥 3번 위**인가 그 **사이**인가.
   코핑이 «각진 두 토막»인가 «한 곡선»인가. 꺾임부 폭·필렛
2. **정면도** — 파단선 위치 · 코핑 상면 단수 · EL 지시 위치
3. **단면도** — 코핑 교축폭 · 헌치
4. **기초 평면도** — 기초 3기인가 · 말뚝 배치(P9 는 22본×2)

## 2단계 — 형상 전략 (보고 후 진행)

P9 코핑은 「정면 윤곽(YZ) × 교축 압출」 ∩ 「평면 윤곽 빗각기둥 2장」으로 섰다.
**꺾이면 그 전제가 깨진다** — 정면도가 투영이라 실제 길이를 안 준다.

후보 셋. 캡처 보고 고른다.

| 방법 | 되는 조건 | 걸림돌 |
|---|---|---|
| 꺾임점에서 **끊어** 두 토막을 각자 압출 | 두 토막이 각각 직선 | 이음매 union — 면으로만 맞닿으면 다음 boolean 이 흘린다 |
| 토막마다 **로컬 좌표계** | 가장 정직 | IR 에 배치 개념이 없다. 코어 변경 |
| 평면 압출 ∩ 정면 압출 | 꺾임이 평면에만 있고 정면이 실제 길이를 줄 때 | 대개 안 준다 |

**끊는 쪽이 유력하다.** loft 는 쓰지 마라 — 결과가 안 닫혀 boolean 에서 샌다(아래).

## 새로 밟은 함정 (또 밟지 마라)

| 증상 | 원인 | 대응 |
|---|---|---|
| **부피는 맞는데 boolean 이 샌다** | **`Loft` 결과가 안 닫힌다.** 4각형 단면도 열린 변 12개. 발산 정리 부피는 정확해 **부피 검사로 절대 안 걸린다** | loft 를 boolean 인자로 쓰지 마라. 평행이동뿐이면 `drift` 압출 |
| 그려진 길이가 실제가 아니다 | **파단선.** 기둥이 6,100 인데 실제 33,800 | `CS-CUTL` 을 본다. 생략량 = 실제 − 도형 (derived) |
| 한 파일에 도형 17벌 | 도면집 스택 | **도곽 블록에서 상자를 계산** |
| 「단면도」 안쪽 선을 부재로 읽음 | **절단면이 아니라 투영** | 치수가 `외곽 − 2×R` 이면 투영 |
| 평면 모서리가 45° 모따기 | 파서가 `bulges` 를 버려 90° 호가 현으로 눌림 | 호 끝점은 정확 → R 은 되찾는다. 링 면적은 못 믿는다 |
| 적분값이 0.2 m³ 샘 | 구간 끝점이 링 꼭짓점 → 스캔라인 교차 수 어긋남 | 내부 노드 구적(가우스). 심프슨 금지 |
| 구조 형상이 **표**로 잡힘 | 평면도 격자가 73행×83열 「표」 | 표 색인에 `layerFilter` |
| `actualMeasurement` 로 단위 판정 실패 | 주요 m 표기 · 상세 mm 표기 (**표시값**이 온다) | 도곽 배율 · 블록 scale · 격자 간격으로 교차검증 |

## P9 에서 통한 방식 — 그대로 가져다 써라

```
단위      도곽 A1×100 · 블록 scale ↔ Φ 텍스트 · 격자 ↔ 「4@1.300」 → 넷 다 1단위=1mm
공통중심  부재 대칭으로 자기검증 (코핑 ±7,000 · 기초 ±3,250 · 기둥 ±4,100)
표고      공통 기준선이 없어도 **표가 준다** — EL.'X' = 코핑상면 + h1 + h2
          6기가 모두 같은 절대표고를 내면 그게 원점이다
받침      평면도(위치·평면치수) × 표(적층고·표고·교축위치) 세 겹 검산
파단      생략량 = 기둥_높이 − 기둥_도형길이  (derived. 손으로 적지 마라)
```

## 아직 안 한 일 (P11 과 별개, 여력 되면)

1. **`manhole1` 재검증** — loft 결과를 union·difference 인자로 쓴다.
   C20 의 함정 위에 서 있을 수 있다. 부피가 맞아 보여도 샜을 수 있다

   정면도의 매달린 대각선 6줄(문양 내부 능선)은 재현 안 한다
3. **`docs/2d-3d-conversion.md` 에 교훈 #34~ 추가** — 위 함정표가 아직 안 옮겨졌다
4. **텍스트 셀렉터** — 기둥 높이·말뚝 길이가 아직 `design` 이다.
