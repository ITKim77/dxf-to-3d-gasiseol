# 가시설 평면도 형상 분석 (S = 1:200)

## 📐 DXF 구조 분석

| 레이어 | 엔티티 | 용도 | 3D 형상 |
|--------|--------|------|---------|
| **A-BASE** | 원 81개<br>선 213개<br>폴리라인 22개 | 기초 파일 및 기초 구조 | 원기둥 (파일) + 토목 구조 |
| **A-GUJO01** | 선 45개<br>폴리라인 8개 | H-보 등 주요 부재 | H-빔 단면 (수평 배치) |
| **A-LINE01** | 폴리라인 291개<br>선 295개 | **토류판 (흙막이판)** | 사각형 판재 (직사각형 패널) |
| **A-LINE04** | 선 219개<br>폴리라인 8개 | 버팀목 (가로/세로) | 각재 (Square Tube) |
| **A-CEN01** | 선 9개 | 센터 파일 (중앙) | 수직 파일 또는 수평 H-보 |
| **A-SLOPE** | 선 88개<br>폴리라인 9개<br>호 7개 | 사면 (흙 표면) | 사면 판재 |

## 🔧 주요 문제점

### 현재 상태 (문제)
```
❌ 무시된 정보:
  - 실제 DXF 폴리라인 형상 (291개 토류판)
  - 부재 간 연결 관계
  - 도형 레이아웃
  - 각 도형의 정확한 좌표

✓ 사용된 정보:
  - 개략적인 부재 개수 추정
  - 텍스트 규격 추출
```

### 해결 방법

#### 1️⃣ 토류판 (A-LINE01) → 2D 사각형 판재
```
291개 폴리라인 → 각각 판재
  - 폴리라인의 폐곡선 = 판재의 평면 범위
  - 두께: 300mm (가시설 토류판 표준)
  - 높이: 평면도 좌표에서 추출

절차:
  1. 각 폴리라인의 경계 좌표 추출
  2. 축척 적용 (×200)
  3. 2D 사각형 → 3D 박스 생성
```

#### 2️⃣ 버팀목 (A-LINE04) → 각재
```
219개 선 + 8개 폴리라인 → 버팀목 구조
  - 선의 길이와 방향 = 버팀목 치수
  - 단면: 200×200mm 또는 250×250mm (표준)
  
절차:
  1. 각 선의 시작/끝 좌표 추출
  2. 선의 방향과 길이 계산
  3. 3D 각재 생성 (BoxGeometry)
```

#### 3️⃣ 센터 파일 (A-CEN01) → 수평/수직 파일
```
9개 선 → 중앙 파일 그룹
  - 패턴 분석: 수평/수직 배치
  
절차:
  1. 선들의 그룹화 (평행선끼리)
  2. 위치와 방향 분석
  3. 파일 타입 결정 (H-파일 vs 수직파일)
```

#### 4️⃣ H-보 (A-GUJO01) → 주요 구조보
```
45개 선 + 8개 폴리라인 → H-보
  - 텍스트 규격: H-300×300×10×15 추출
  - 선의 위치 = 보의 배치
  
절차:
  1. 선들을 Y좌표로 그룹화
  2. 각 그룹이 하나의 보 = 여러 선의 집합
  3. 규격 적용: H-300×300
```

#### 5️⃣ 기초 파일 (A-BASE) → 원형 파일 + 기초 토목
```
81개 원 + 213개 선 + 22개 폴리라인
  - 원: 파일 위치 (φ1000)
  - 선: 기초 연결 구조
  - 폴리라인: 기초판 (캡)

절차:
  1. 원 → 원기둥 (깊이 8000mm)
  2. 선 → 기초보 (각재 또는 H-보)
  3. 폴리라인 → 기초판
```
