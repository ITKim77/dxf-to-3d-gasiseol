## 🔍 부재별 세부 분석

### 1. A-GUJO01 - 주요 구조 (45개 선)

**패턴**:
```
선 0, 1, 2, 3, 4     (1100, 141, 160, 160, 1300mm) → 부재 A
선 5, 6, 7, 8, 9     (1100, 141, 160, 160, 1300mm) → 부재 B
선 10, 11 (2180, 2180mm) → 부재 C
선 20 (2890mm) → 부재 D
선 38~44 (2020, 5918mm) → 부재 E~?
```

**추정**:
- ~9~10개 주요 부재
- 각 부재는 5개 선 (사각형 또는 H-형)
- 최대 길이 5918mm → 높이 또는 깊이

**3D 형상**:
- H-보: 300×300×5918mm 또는 더 큼
- 또는 조합 구조 (여러 부재의 조립)

### 2. A-BASE - 기초 (213개 선, 81개 원, 22개 폴리라인)

**확인된 것**:
- 81개 원 = 81개 기초 파일 (φ1000×8000mm)
- 28개 선 = 기초 보 (250×250×길이 가변)
- 22개 폴리라인 = 기초판

**패턴**:
- POINT 4개 = 파일 배치 그룹 (각 그룹 ~20개 파일)
- 선들의 교점 = 파일 위치 확인

### 3. A-CEN01 - 센터 (9개 선)

**확인된 것**:
- 9개 선
- 평균 길이 2141mm
- 3개 그룹 (600~5944mm)

**해석**:
- H-파일: 수평 배치 (3개 그룹)
- 또는 수직 파일 (3개 + 추가)

### 4. A-LINE01 - 토류판 (291개 폴리라인 + 295개 선)

**확인된 것**:
- 291개 폴리라인 = 토류판 패널
- 295개 선 = 보강선 또는 패널 경계

**현황**:
- 현재 22개만 추출 (큰 패널)
- 269개 누락 (작은 패널 또는 노이즈)

**필터 조정**:
- 필터 기준: 10mm 이상 (현재 100mm)
- 또는 면적 기준: 10,000 mm² 이상

## 🔧 다음 구현 단계

### Phase 1: 선 그룹화 (우선순위 높음)
```
A-GUJO01: 선을 5개씩 그룹화 → 부재 윤곽선 → 3D 박스
A-BASE: 선을 분석하여 파일 배치 확인

구현:
  1. 선의 길이 패턴 분석
  2. 반복되는 길이 조합 탐지
  3. 각 조합 = 1개 부재
  4. 부재의 경계 좌표 추출
  5. 3D 형상 생성
```

### Phase 2: 토류판 필터 완화
```
A-LINE01: 면적 기준으로 재필터링
  - 현재: 22개 (폭×높이 > 100mm)
  - 개선: 270개+ (폭×높이 > 10,000 mm²)

구현:
  1. 폴리라인 면적 계산
  2. 10,000~1,000,000 mm² 범위의 패널만
  3. 300mm 두께 적용
```

### Phase 3: 센터 파일 분류
```
A-CEN01: 방향에 따라 분류
  - 수평 파일: dy < 1000mm → H-파일
  - 수직 파일: dx < 1000mm → 수직 파일

구현:
  1. 각 선의 방향 계산
  2. 수평/수직 구분
  3. 규격 적용 (H-200×200 또는 원형 φ1000)
```
